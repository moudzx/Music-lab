## Presets

| Preset | Sound |
| --- | --- |
| Chiptune | Classic 8-bit console sound |
| Lo-fi | Gritty, dusty, reduced fidelity |
| Nightcore | Faster and higher |
| Vaporwave | Slower and lower |
| Telephone | Narrow, tinny band |

## 8-bit crusher

Build your own retro sound with three controls.

- **Rate** lowers the sample rate for that aliased, crunchy texture
- **Bits** lowers the bit depth, down to 1 bit
- **Drive** pushes the wave toward a square shape

Start with 8000 Hz, 4 bits, drive 3 for a console feel.

## Edit

- Trim, cut, copy, paste
- Silence or reverse a region
- Fade in and fade out
- Normalize the volume
- Undo and redo

## Effects

- **Speed and pitch:** slow it down or speed it up, pitch follows
- **Filter:** low pass to muffle, high pass to thin out
- **Echo:** delay time, feedback and mix
- **Distortion:** heavy saturation

## Remix

- **Chop:** slice a region into 4, 8, 16 or 32 pieces
- **Shuffle:** rearrange the slices in random order
- **Flip:** reverse random slices
- **Stutter:** repeat the start of each group of four slices
- **Reverse order:** play the slices backwards
- **Repeat:** loop a region up to 16 times to build a longer track

## Playback

- Play, pause and stop
- Loop the selected region to audition changes
- Space toggles play and pause
- Ctrl+Z or Cmd+Z undoes

## Tips

- Select a single bar, then chop and shuffle it for quick beat variations.
- Run Chiptune first, then Echo for a spacious retro lead.
- Try Vaporwave, then a low pass filter for a smooth, dreamy loop.
- Reverse a short region before a drop for a build-up effect.

## Formats

Opens any audio format your browser can play, including WAV, MP3, OGG and AAC. Exports 16-bit WAV.
